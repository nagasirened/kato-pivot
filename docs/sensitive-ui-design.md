## Problem Statement

为敏感词系统（kato-sensitive）开发一套 Vue + Element Plus 后台管理页面，供运营人员使用。系统需要支持敏感词的增删改查、测试、导入导出、日志查看等功能，风格为深色科技风。

## What Makes This Cool

1. **深色科技风** — 黑色/深灰背景，渐变强调色，视觉上有质感
2. **实时检测体验** — 输入文本即时看到命中结果，有脱敏预览
3. **批量操作** — Excel导入导出，运营效率高
4. **可复用的后台模板** — 做成之后可以套到其他后台项目上

## Constraints

- 前端技术栈：Vue 3 + Element Plus + Vite + Pinia
- 后端技术栈：Spring Boot（已有）
- 深色科技风格（用户指定）
- 目标用户：运营人员（非技术背景）

## Premises

1. 后端分为服务端（管理API，端口8080）和客户端（检测API，端口8081）
2. 敏感词数据模型包含：word、level、status、category、remark
3. 导入导出使用 Excel 文件流，前端需处理 blob 下载和文件上传
4. 检测结果返回命中词列表、最高等级、分类，可选返回脱敏文本

## Approaches Considered

### Approach A: 精简版（2个页面）
- 只做敏感词管理和测试页面
- 文件少，快速交付
- 缺点：功能残缺，导入导出、日志都没有

### Approach B: 完整后台模板（推荐）
- 6个完整页面，封装通用组件
- 包含Dashboard统计、敏感词管理、测试、导入导出、日志
- 优点：功能完整，可作为后台项目模板复用

## Recommended Approach

**采用方案 B：完整后台模板**

#### 用户旅程

**场景1：首次使用（无敏感词）**
1. 打开后台 → Dashboard首页
2. 点击"敏感词管理" → 空状态："暂无敏感词，立即新增"
3. 点击"新增" → 弹窗填写 → 保存 → 返回列表

**场景2：日常查找**
1. 进入敏感词管理 → 默认显示全量列表
2. 使用筛选栏（等级/状态/分类）→ 快速定位
3. 点击编辑 → 修改 → 保存

**场景3：批量导入**
1. 点击"导入导出" → 下载模板
2. 填写Excel → 上传
3. 查看导入结果

**场景4：敏感词检测**
1. 点击"敏感词测试" → 进入检测页
2. 输入或粘贴文本 → 点击"检测"（或300ms防抖自动触发）
3. 查看结果：是否包含、命中词、高亮位置
4. 开启"脱敏预览" → 查看替换后的安全文本

#### 1. Dashboard（统计面板）
- 敏感词总数卡片（按等级区分颜色）
- 分类分布图（简单横向柱状图，用 CSS 实现）
- 最近操作日志（最近5条）
- 快捷入口按钮

#### 2. 敏感词管理（List.vue）
- 顶部：搜索栏（关键词模糊搜索）+ 筛选下拉（等级/状态/分类）
- 表格：敏感词列表，支持分页
- 行内操作：编辑、禁用/启用、删除
- 底部：新增按钮 + 导入按钮 + 导出按钮
- 编辑和新增共用 Edit.vue 弹窗

#### 3. 敏感词测试（Index.vue）
- 左侧：文本输入区（大文本框，textarea）
- 右侧：检测结果展示区
  - 是否包含敏感词（红/绿标签）
  - 命中数量
  - 最高等级（URGENT红色/MEDIUM橙色/NORMAL黄色）
  - 命中分类标签
  - 命中词列表（高亮显示位置）
  - 脱敏预览开关（开启后显示替换后的文本）
- 底部：检测按钮 + 清空按钮
- **防抖逻辑**：文本输入停止300ms后自动触发检测，无需手动点击

#### 4. 导入导出（Import.vue）
- 导入：文件上传组件，下载模板按钮
- 导出：筛选条件 + 导出按钮
- 导入结果：成功/失败数量统计

#### 5. 操作日志（List.vue）
- 表格展示操作记录
- 列：操作类型、操作内容、操作人、操作时间
- 支持分页

### API 接口对接

**架构决策：两个独立的 axios 实例**

```javascript
// src/api/manager.js — 管理端 API（8080端口）
import axios from 'axios'
const managerApi = axios.create({
  baseURL: 'http://localhost:8080'
})

// src/api/check.js — 检测端 API（8081端口）
import axios from 'axios'
const checkApi = axios.create({
  baseURL: 'http://localhost:8081'
})
```

**敏感词管理 API（服务端 8080）— 使用 managerApi**

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 分页查询 | GET | /sensitive/v1/word/page | current, size, word, level, status |
| 详情 | GET | /sensitive/v1/word/{id} | - |
| 新增 | POST | /sensitive/v1/word | body: SensitiveWord |
| 更新 | PUT | /sensitive/v1/word | body: SensitiveWord |
| 删除 | DELETE | /sensitive/v1/word/{id} | - |
| 导入 | POST | /sensitive/v1/word/import | multipart file |
| 导出 | GET | /sensitive/v1/word/export | query params as filter |
| 模板下载 | GET | /sensitive/v1/word/template | - |
| 操作日志 | GET | /sensitive/v1/word/log/page | current, size |

**敏感词检测 API（客户端 8081）— 使用 checkApi**

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 检测 | POST | /sensitive/v1/check | body: {text, wordType, fuzzyMatch, sanitize} |
| 精确检测 | POST | /sensitive/v1/check/exact | body: {text} |
| 模糊检测 | POST | /sensitive/v1/check/fuzzy | body: {text} |

### 关键实现细节

1. **Excel 文件下载**：使用 axios 配置 `responseType: 'blob'`，创建 blob URL 触发下载
2. **Excel 文件上传**：使用 el-upload 组件，手动上传，FormData 封装
3. **表格深色主题**：通过 Element Plus CSS 变量覆盖实现（见上方样式规范）
4. **检测结果高亮**：使用正则匹配替换，在原文中用 `<mark>` 包裹命中词
5. **脱敏预览**：根据命中的 startIndex 和 endIndex，替换对应位置字符
6. **检测防抖**：使用 lodash.debounce 或自定义实现，300ms 延迟
7. **全局错误处理**：axios 拦截器统一处理 401/403/500 错误，显示 Toast 提示

### 响应式与无障碍设计

**断点定义：**
| 断点 | 宽度 | 侧边导航 | 内容区 |
|------|------|----------|--------|
| Desktop | >= 1200px | 固定200px | 多列布局 |
| Tablet | 768px - 1199px | 可折叠icon模式 | 单列布局 |
| Mobile | < 768px | 隐藏，汉堡菜单触发 | 全宽卡片 |

**无障碍要求：**
- 所有交互元素可键盘访问（Tab / Enter / Escape）
- 表单输入框有对应的 `<label>` 或 `aria-label`
- 颜色对比度满足 WCAG AA 标准（文本 >= 4.5:1，大文本 >= 3:1）
- 按钮和链接有 focus 态高亮（使用 `$accent-blue`）
- 图片有 `alt` 属性（即使是装饰性图片用 `alt=""`）
- 错误提示与表单字段关联（`aria-describedby`）
